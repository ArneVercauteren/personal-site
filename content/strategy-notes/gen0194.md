title: Reflection on live performance
date: 2026-10-06
---

After a few months of tracking (with some extra rebalances at the start due to paper-trading bugs), it has become fairly clear that this strategy does not perform well live. As we can see, the OOS performance matches the historical performance very closely. The fact that this strategy flopped as soon as it was traded live points to a problem in the backtesting engine. The main suspects are: 1) A bug in the engine that allowed data leakage into OOS, effectively allowing the strategy to be trained using both the historical data and the OOS data. 2) Excessive OOS tests with many different strategies. Running the OOS test on many strategies becomes effectively the same as training on OOS data. The test becomes less effective the more it is used.

Out of these two, the first seems most probable. Since this first strategy was found and published, the engine has been heavily polished and audited, and various new anti-overfitting techniques have been introduced. Future paper-trading strategies should give a better view of the problem, if it is still present after these reworks.
